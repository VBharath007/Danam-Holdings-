# Danam Holdings Website
React 19 + Vite + TypeScript + Tailwind CSS v4 + React Router

## Run
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in /dist (upload to Netlify / any host)

## Edit content
- All text (address, phone, services, projects, clients, team, FAQ, testimonials): src/data/company.ts
- Brand colours (taken from brand.webp): src/index.css -> @theme
- Logo icon: public/dhlogo.webp   Circle brand logo: public/brand.webp
- Photos: public/homehero/

## IMPORTANT before going live
Testimonials in src/data/company.ts are SAMPLES. Replace with real client feedback.
